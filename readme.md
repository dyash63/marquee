Marquee

Personal movie & series watchlist. Find where to watch, track what you’ve seen, get notified about new episodes.

100% free — uses the free TMDB API (no credit card). Static site, no backend.

Host on GitHub Pages





Create a new GitHub repo.



Upload index.html (and this README if you want).



Settings → Pages → Source → Deploy from a branch → main / root.



Open https://<you>.github.io/<repo>/.

Get a free TMDB API key (1 minute)





Sign up: themoviedb.org/signup



Go to Settings → API → request a key (choose Developer)



Copy the API Key (v3 auth) — not the Read Access Token



In Marquee, open TMDB API key (free) and paste it. Saved only in your browser.

No payment, no usage fees for personal use.

Features





Search movies & series (typeahead)



Region-specific streaming / rent / buy / free options (via JustWatch data on TMDB)



To-watch / Watched lists + Movies / Series filter



Expand series for season counts & next episode



Optional “new episode today” checks



Export / import JSON backup

Privacy

Watchlist + API key stay in your browser (localStorage). Nothing is sent to any server of ours — only TMDB when you search.
